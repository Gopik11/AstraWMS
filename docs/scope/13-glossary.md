# Z — Glossary

| Term | Definition |
|---|---|
| 3PL | Third-party logistics provider operating warehouses for multiple clients (owners) |
| ABC / XYZ | Classification by velocity/value (ABC) and by demand variability (XYZ) |
| ADR | European agreement on international carriage of dangerous goods by road |
| AGV / LGV | Automated / laser-guided vehicle, following fixed paths or reference markers |
| AI (GS1) | Application Identifier: prefix in GS1 barcodes defining the data element (e.g., 01 GTIN, 10 lot, 17 expiry, 21 serial, 00 SSCC) |
| ALE / IDoc | SAP Application Link Enabling / Intermediate Document: SAP's asynchronous messaging framework and format |
| AMR | Autonomous mobile robot navigating without fixed infrastructure |
| AOS | Automation Orchestration Service (AstraWMS component) |
| AQL | Acceptable quality limit (ISO 2859-1 sampling) |
| ASN | Advance shipping notice (EDI 856 / DESADV) |
| ASRS | Automated storage and retrieval system |
| BAPI | SAP Business API: RFC-enabled function module with a stable business interface |
| BFF | Backend-for-frontend service tailored to a client type |
| BOL | Bill of lading |
| Canonical model | ERP-neutral message schemas used inside AstraWMS |
| CDC | Change data capture |
| Check digit | Short code printed on a location label and scanned or spoken to confirm the operator is at the right place |
| Cluster picking | Picking multiple orders simultaneously into separate containers |
| Cross-dock | Moving goods from inbound to outbound with no or minimal storage |
| DG / HazMat | Dangerous goods / hazardous materials |
| DSCSA | US Drug Supply Chain Security Act |
| EPCIS | GS1 standard for sharing supply chain visibility events |
| FBDI | Oracle Fusion File-Based Data Import |
| FEFO / FIFO / LIFO | First-expired-first-out / first-in-first-out / last-in-first-out |
| GTIN | Global Trade Item Number |
| GTP | Goods-to-person picking |
| HU | Handling unit (SAP): physical unit of packaging material + contents |
| ISD | Interface Specification Document |
| LMS | Labor Management System |
| LPN | License plate number: unique ID of a container (pallet, case, tote) |
| MCS | Multi-carrier shipping system |
| MHE | Material handling equipment |
| Movement type | SAP key classifying a goods movement (e.g., 101 GR, 601 GI for delivery) |
| OAG BOD | Open Applications Group Business Object Document (used by Oracle XML Gateway) |
| Open Interface | Oracle EBS staging tables processed by concurrent programs into base tables |
| Outbox / Inbox pattern | Reliable messaging patterns for publishing and deduplicating messages with a database transaction |
| P&D point | Pickup-and-deposit location between equipment types |
| PGI / PGR | Post goods issue / post goods receipt (SAP) |
| PTL | Pick-to-light / put-to-light |
| QI | Quality inspection stock |
| RMA | Return material authorisation |
| RPO / RTO | Recovery point / recovery time objective |
| RTLS | Real-time locating system |
| SCIM | System for Cross-domain Identity Management |
| Shipment Request / Advice | Oracle EBS third-party warehouse messages for outbound demand and confirmation (≈ EDI 940 / 945) |
| Slotting | Assignment of items to storage/pick locations |
| SLoc | SAP storage location |
| SSCC | Serial Shipping Container Code (GS1, 18 digits) |
| Subinventory | Oracle stock partition within an inventory organisation |
| Task interleaving | Combining different task types in one operator's sequence to reduce empty travel |
| Ti-Hi | Cases per pallet layer (Ti) × number of layers (Hi) |
| TOR | Time out of refrigeration |
| UD | Usage decision (SAP QM) |
| VDA 5050 | Standard interface between AGV/AMR fleets and master control |
| VAS | Value-added services |
| Wave / Waveless | Batch release of work vs continuous capacity-driven release |
| WCS / WES | Warehouse control system / warehouse execution system (MHE-level control) |
